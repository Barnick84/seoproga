# Архитектура и Описание Проекта (seo-auto-cluster)

## Описание проекта
**seo-auto-cluster** — это комплексная платформа для автоматизации SEO-процессов, объединяющая веб-интерфейс на Node.js и мощный аналитический бэкенд на Python. 

Главная цель проекта — автоматический сбор поисковых запросов (семантического ядра), их кластеризация на основе сходства поисковой выдачи (SERP) Яндекса, интеграция с Яндекс.Вебмастером, а также генерация и анализ контента с использованием ИИ (OpenAI) и биржи контента Miratext. Проект включает собственную биллинговую систему для тарификации операций.

---

## Основной функционал

1. **Сбор и анализ выдачи (SERP)**
   - Получение топ-10 результатов выдачи Яндекса по запросам через **XMLRiver**.
   - Умная кластеризация запросов на основе алгоритма Жаккара с учетом веса позиций (Hard/Soft кластеризация).

2. **Интеграция с Яндекс.Вебмастер**
   - Автоматическая загрузка поисковых запросов и кликовой статистики по сайтам пользователя.
   - Проверка привязки доменов и мониторинг позиций.

3. **Семантический анализ и контент**
   - Интеграция с **Miratext** для заказа SEO-статей.
   - Использование LLM (через **OpenAI** / Hydra) для семантического анализа, извлечения LSI-слов, автоматического именования кластеров и распределения контента.

4. **Веб-приложение и Личный Кабинет**
   - Полноценный интерфейс (`nodejs-app`) для управления сайтами, минус-словами, запуска кластеризации и распределения (мэппинга) кластеров по страницам.
   - Система регистрации, авторизации и сессий пользователей.
   - Биллинг-модуль: пополнение баланса через Tegro Money и автоматическое списание средств за каждую операцию (кластеризация, съем позиций).

5. **Фоновые задачи и Дашборды**
   - Встроенный планировщик задач (`task_manager.py`, `worker.py`) для долгих процессов.
   - Информативный аналитический дашборд на базе **Streamlit** (`streamlit_app.py`).

## Структура проекта

Проект разделен на несколько логических слоев:

### 1. Веб-сервер и Интерфейс (`nodejs-app/`)
*Отвечает за маршрутизацию, API для фронтенда и запуск Python-скриптов.*
- **`server.js`** — основной Express-сервер. Обеспечивает работу API, авторизацию, биллинг, и запуск процессов через `child_process`.
- **`public/`** — статические файлы фронтенда (HTML, CSS, JS), включая интерфейс работы с кластерами (`cluster.html`).
- **`scripts/`** — Python-скрипты, которые вызываются из Node.js (например, `run_clustering.py`, `user_auth.py`, `run_mapping.py`).
- **`db.js`** — конфигурация пула подключений к MySQL для Node.js.

### 2. Ядро и Сервисы (Python Backend - `services/`)
*Отвечает за бизнес-логику, вычисления и взаимодействие со сторонними API.*
- **`clustering.py`** — ядро алгоритма сравнения SERP и кластеризации.
- **`xmlriver_client.py`** — клиент для API XMLRiver.
- **`yandex_webmaster.py`** — клиент для API Яндекс.Вебмастера.
- **`miratext_client.py`** — клиент для работы с биржей Miratext.
- **`seo_agent.py` & `seo_workflow.py`** — агенты и пайплайны взаимодействия с LLM (OpenAI) для сложных текстовых задач.
- **`custom_analyzer.py`** — модули глубокого текстового анализа страниц и контента.
- **`cache.py` & `semantic_core.py`** — работа с кэшированием (SQLite) и основными данными семантики.
- **`worker.py` & `task_manager.py`** — управление асинхронными фоновыми задачами.

### 3. Инфраструктура и Конфигурация
- **`main.py`** — CLI-утилита для ручного запуска различных режимов автоматизации (XMLRiver, Yandex, Miratext).
- **`streamlit_app.py`** — графический аналитический дашборд (Streamlit).
- **`.env` & `config.py`** — файлы безопасного хранения настроек (токены, ключи БД, настройки тарифов).
- **`docker-compose.yml`** — конфигурация Docker для локального развертывания MySQL базы данных (`seo_auto_mysql`).
- **`requirements.txt` / `package.json`** — списки зависимостей для Python и Node.js.
